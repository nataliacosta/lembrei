Fluxo de deploy: commit na branch → PR para a main → merge sem esperar aprovação → deploy a partir da main

Para cada pedido de mudança, crie uma branch nova a partir da main atualizada, com nome descritivo (ex.: muda-tela-contratos), e use-a no fluxo de deploy.

Antes de alterar o código, aplique a mudança no canvas de design (https://claude.ai/artifact/EdDSKjisNssLd227EGqUgg) e peça para a dona do repositório conferir. Só depois da aprovação altere o código e siga o fluxo de deploy.
